# Проверка входа и уведомлений на телефоне

Вход делает сайт внутри приложения; приложение только узнаёт о входе и выходе (`GORODAPP_WEB_SESSION` /
`GORODAPP_WEB_LOGOUT`) и регистрирует телефон для уведомлений.

1. Открыть приложение без входа — видна главная, можно смотреть Маркет, Еду, Ивент.
2. Положить товар в корзину и начать оформление — сайт попросит войти (МТС ID или код из SMS), согласия.
3. После входа приложение один раз спросит разрешение на уведомления.
4. Подождать больше 15 минут (или свернуть приложение на час) — вход сохраняется, профиль и бонусы открываются.
5. Закрыть приложение полностью и открыть снова — вход сохраняется.
6. Android: «Назад» закрывает открытый товар/корзину/категорию, с главной — выходит из приложения.
7. Ссылки на Instagram / телефон / почту открываются в соответствующих приложениях, не внутри.
8. Выйти из профиля — следующий запуск без входа.
