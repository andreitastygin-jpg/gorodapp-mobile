# Google Play Console — что нажимать, по шагам

Тексты и ответы для анкет лежат в [listing-ru.md](listing-ru.md), картинки — в этой папке. Всё вписывается вручную.

**Что можно поменять потом:** тексты, картинки, анкеты, само приложение (новая сборка) — в любой момент,
после каждого изменения короткая проверка Google. **Нельзя поменять:** имя пакета `ru.gorodapp.mobile` (закрепляется
первой загрузкой) и ключ подписи.

## 1. Создать приложение

Play Console → «Создать приложение» (Create app):

- Название: `GorodApp: магазины и еда`
- Язык по умолчанию: русский
- Приложение (не игра), бесплатное
- Отметить согласия → «Создать приложение»

## 2. Анкеты (раздел «Содержание приложения» / App content)

На главной странице приложения — список «Настройте приложение». Ответы — в `listing-ru.md`:

| Анкета | Ответ |
|---|---|
| Политика конфиденциальности | `https://gorodapp.ru/privacy` |
| Доступ к приложению | Номер и код для проверяющего — шаг 6 (пока не включено на сервере — пропустить) |
| Реклама | Нет |
| Возрастной рейтинг | E-mail gorodapp.info@yandex.ru; не игра; насилия, азартных игр, общения между пользователями нет; алкоголь/табак — по факту |
| Целевая аудитория | 18+ |
| Безопасность данных | Таблица в `listing-ru.md` |
| Финансовые функции, здоровье, госприложение, новости | Нет |
| Удаление аккаунта | `https://gorodapp.ru/delete-account` |

## 3. Страница в магазине («Основная страница» / Main store listing)

- Название, краткое и полное описание — из `listing-ru.md`
- Значок — `icon-512.png`; баннер — `feature-graphic-1024x500.png`
- Скриншоты телефона — `screenshots/screenshot-1.png` … `screenshot-5.png`, по порядку
- Скриншоты планшетов — пропустить (приложение для телефонов)
- Категория — «Покупки»; e-mail, сайт

## 4. Сборка для магазина (файл AAB)

В Терминале на Mac (вход в Expo уже выполнен):

```bash
cd ~/GorodApp-Claude/gorodapp-mobile && npx eas-cli build -p android --profile production
```

Сборка идёт 15–30 минут, в конце — ссылка на файл `.aab`. Скачайте его.

## 5. Закрытое тестирование

«Тестирование» → «Закрытое тестирование» → трек (обычно называется Alpha) → «Управлять треком»:

1. Страны — Россия.
2. Тестировщики — «Создать список»: e-mail Google-аккаунтов. Нужно **не меньше 12 человек 14 дней подряд**;
   возьмите 15–20 с запасом: если кто-то выйдет из теста, его дни перестанут считаться.
3. «Создать выпуск». Google предложит «Подписание приложений в Google Play» — согласиться. Загрузить `.aab`.
   Примечания к выпуску: «Первая версия».
4. «Далее» → «Сохранить» → «Отправить на проверку». Кнопка заработает, когда заполнены все анкеты шага 2.
5. После одобрения (от нескольких часов до нескольких дней) на странице трека появится ссылка-приглашение.
   Тестировщик открывает её на телефоне под тем же Google-аккаунтом → «Стать тестировщиком» → ставит приложение из Google Play.
6. Пусть тестировщики пользуются приложением: после 14 дней Google спросит, как прошло тестирование.

Необязательно: «Внутреннее тестирование» выпускается за минуты, без проверки Google. Это удобно, чтобы сначала
поставить приложение себе. В зачёт 14 дней оно не идёт.

## 6. Номер для проверяющего Google (до «Отправить на проверку»)

Проверяющий не получит SMS от МТС, поэтому для одного номера сервер принимает постоянный код вместо МТС ID
(доработка в ветке бэкенда `docs/backup-owner-memo`). Остальные номера входят как раньше.

1. **Выберите номер и код.** Номер — тот, которым на сайте никто не входит (лучше ваша запасная SIM): владелец этого
   номера не сможет войти через МТС ID, пока вход для проверяющего включён. Код — 6 цифр, не `000000` и не `123456`.
2. **Влейте ветку бэкенда и выложите** как обычно.
3. **Впишите на сервере** в файл `.env` бэкенда две строки и перезапустите его (`pm2 restart gorod-backend`):
   `STORE_REVIEW_PHONE="+7…"` и `STORE_REVIEW_CODE="……"`. Нигде больше номер и код не храните — только на сервере
   и в анкете Google.
4. **Проверьте сами:** gorodapp.ru → «Профиль» → номер → «Войти по номеру телефона» → код → «Подтвердить».
   SMS не придёт — так и должно быть. Первый вход создаёт отдельный аккаунт, заполните имя.
5. **Анкета «Доступ к приложению»** → «Часть функций ограничена» → «Добавить инструкции». Имя пользователя — номер,
   пароль — код, в поле инструкций:

   > Open «Профиль» (Profile) at the bottom. Enter the phone number without +7 and tap «Войти по номеру телефона».
   > No SMS is sent for this number: enter the code in «Код из SMS» and tap «Подтвердить». If asked, enter any name,
   > accept both checkboxes and tap «Продолжить». Payment is cash on delivery, test orders are not paid.

Заказы с этого номера уходят продавцам как обычные — потом их удаляете. Выключить вход для проверяющего: удалить
эти две строки из `.env` и перезапустить бэкенд.

## 7. Выпуск для всех

Через 14 дней на главной Play Console — «Подать заявку на доступ к рабочей версии» (Apply for production):
короткая анкета о тестировании, ответ Google обычно до 7 дней. Потом «Рабочая версия» → «Создать выпуск» →
тот же или более новый `.aab` → проверка → приложение в Google Play.
